🤖 Agentforce Data Model

Relationships between Agents, Topics, and Instructions

📋 Key Components

Bot (Agent): The main agent interface (Einstein Copilot or custom agent)
GenAiPlanner: The AI orchestration engine using ReAct methodology
Topics (Plugins): Functional capabilities grouped by domain (e.g., HR, CRM, Sales)
GenAi Functions: Executable actions like Flows, Apex methods, or API calls
Instructions: Prompt templates that define agent personality, tone, and behavior

🔗 Relationships

1-to-1: Bot ↔ GenAiPlanner (Each agent has one planner)

1-to-Many: GenAiPlanner → Topics (Planner can use multiple topics/plugins)

1-to-Many: GenAiPlanner → Functions (Planner can execute multiple functions)

Many-to-Many: Topics ↔ Functions (Topics contain multiple functions, functions can be in multiple topics)

1-to-Many: Bot → Instructions (Multiple prompt templates guide agent behavior)
